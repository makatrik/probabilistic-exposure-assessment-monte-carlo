# ProbabilisticExposureEstimation_MonteCarlo
A custom-made R script was developed to estimate probabilistic oral human exposure using Monte Carlo simulations. The code is chemical-agnostic and can be applied to any chemical, provided that consumption and occurrence data are structured in accordance with the input requirements defined in the code. Exposure estimation is based on combining consumption data from biomonitoring studies and/or databases with occurrence data of chemicals in food items, typically sourced from the scientific literature.

The code was used to estimate probabilistc human exposure to mycotoxins and has been published at Food and Chemical Toxicology,
'Exploring the Relationship between Daily Intake and Renal Excretion of the Mycotoxins T-2 and HT-2 Toxin in Humans'
